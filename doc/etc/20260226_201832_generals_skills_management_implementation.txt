## 本次实现内容

### 1. 武将管理功能

#### 1.1 武将管理页面 (admin/generals.php)
**功能：**
- 查看武将列表（支持分页、搜索）
- 创建新武将（支持设置所有属性）
- 编辑现有武将
- 删除武将
- 稀有度徽章显示（B/A/S/SS/P，不同颜色）
- 元素徽章显示（六种元素，不同颜色）
- 模态框表单，提升用户体验

**武将属性：**
- 名称（必填）
- 来源（可选）
- 稀有度（B/A/S/SS/P）
- COST（1.0-4.0）
- 元素（六种元素之一）
- 攻击力、防御力、速度、智力
- 等级

#### 1.2 技能管理页面 (admin/skills.php)
**功能：**
- 查看技能列表（支持分页、搜索）
- 创建新技能
- 编辑现有技能
- 删除技能
- 技能类型徽章显示（主动/被动/自带/装备）
- 效果类型和值显示

**技能属性：**
- 技能名称（必填）
- 技能类型（主动/被动/自带/装备）
- 效果类型（攻击力提升、防御力提升、速度提升等）
- 效果值（数值）
- 效果描述
- 技能等级
- 槽位

#### 1.3 API 接口
**api/get_general.php：**
- 获取单个武将的详细信息
- 返回格式：JSON（包含所有武将属性）
- 权限检查：需要管理员权限

**api/get_skill.php：**
- 获取单个技能的详细信息
- 返回格式：JSON（包含所有技能属性）
- 权限检查：需要管理员权限

### 2. 类方法扩展

#### 2.1 General 类扩展
**新增方法：**
- `setName($name)` - 设置武将名称
- `setSource($source)` - 设置武将来源
- `setRarity($rarity)` - 设置稀有度
- `setCost($cost)` - 设置 COST 值
- `setElement($element)` - 设置元素
- `setAttack($attack)` - 设置攻击力
- `setDefense($defense)` - 设置防御力
- `setSpeed($speed)` - 设置速度
- `setIntelligence($intelligence)` - 设置智力
- `save()` - 保存武将更改到数据库
- `delete()` - 删除武将（级联删除相关技能和分配记录）

**删除方法特性：**
- 使用事务确保数据一致性
- 先删除相关技能
- 再删除武将分配记录
- 最后删除武将本身

#### 2.2 GeneralSkill 类扩展
**新增方法：**
- `setSkillName($skillName)` - 设置技能名称
- `setSkillType($skillType)` - 设置技能类型
- `setSkillEffect($skillEffect)` - 设置技能效果（支持数组或JSON字符串）
- `getSkillEffect()` - 获取技能效果（返回数组格式）
- `save()` - 保存技能更改到数据库
- `delete()` - 删除技能

### 3. 权限系统扩展

#### 3.1 AdminManager 类新增权限
在 PERMISSIONS 常量中添加：
- `manage_generals` => 3 - 管理武将（查看）
- `create_generals` => 3 - 创建武将
- `edit_generals` => 3 - 编辑武将
- `delete_generals` => 4 - 删除武将
- `manage_skills` => 3 - 管理技能（查看）
- `create_skills` => 3 - 创建技能
- `edit_skills` => 3 - 编辑技能
- `delete_skills` => 4 - 删除技能

**权限等级对应：**
- 等级 1-2：只能查看武将和技能
- 等级 3-4：可以创建、编辑武将和技能
- 等级 5+：可以删除武将和技能

### 4. 管理后台导航更新

#### 4.1 admin/index.php 更新
在导航菜单中添加：
- ⚔️ 武将管理 - 链接到 generals.php
- ✨ 技能管理 - 链接到 skills.php

### 5. 数据库更新

#### 5.1 SQL 更新文件
**sql/update_generals_simple.sql：**
- 修改 generals 表的 owner_id 字段，允许值为 0
- 值为 0 表示通用武将池，不属于任何玩家
- 添加索引以优化查询

**设计理念：**
- 创建的武将 owner_id 设为 0，属于通用武将池
- 玩家通过抽卡系统从通用武将池中获得武将
- 获得后 owner_id 更新为玩家 ID

## 使用说明

### 1. 应用数据库更新
```bash
mysql -u root -p fireseed_engage < sql/update_generals_simple.sql
```

或在 phpMyAdmin 中执行该 SQL 文件。

### 2. 访问管理界面
1. 登录游戏（确保用户有管理员权限）
2. 访问 `http://localhost:8000/admin/`
3. 点击导航栏的「武将管理」或「技能管理」

### 3. 创建武将流程
1. 点击「+ 创建武将」按钮
2. 填写武将信息：
   - 武将名称（必填）
   - 来源（可选）
   - 稀有度（B/A/S/SS/P）
   - COST（1.0-4.0）
   - 元素（六种元素之一）
   - 基础属性（攻击、防御、速度、智力）
3. 点击「保存」

### 4. 创建技能流程
1. 点击「+ 创建技能」按钮
2. 填写技能信息：
   - 技能名称
   - 技能类型（被动/主动/自带/装备）
   - 效果类型
   - 效果值
   - 效果描述
3. 点击「保存」

### 5. 权限配置
不同管理员等级可执行的操作：

| 等级 | 权限 |
|-----|------|
| 1-2 | 查看武将和技能 |
| 3-4 | 创建、编辑武将和技能 |
| 5+ | 删除武将和技能 |
