   - emoji_fallback：不输出正式图像请求，直接显示 Emoji。
2. 新安装默认使用 image 模式。
3. 提供 sql/upgrade_20260718_image_resources.sql 供现有安装幂等补充配置。
4. 后台 config.php 新增专用下拉选择、即时当前模式预览和保存入口。
5. 图像模式配置使用严格枚举验证；后台所有相关 POST 表单补齐 CSRF，开关关闭值可正确提交。

Fireseed Engage - Image Resources, General Card Visuals, and Emoji Fallback
Implementation time: 2026-07-18 01:55:24 -04:00

1. Scope

- Implemented every one of the 45 icon families specified by
  doc/etc/image_resources_specification.txt.
- Added PNG and WebP variants, required density variants, and seven CSS
  sprite sets.
- Added five transparent rarity frames at 400×600 and 800×1200.
- Added original portraits for all G001–G014 generals at 512×768 and
  1024×1536 in PNG and WebP.
- Added a layered 2:3 general-card renderer with dynamic identity, level,
  cost, stats, skill, element treatment, rarity frame, and complete fallback.
- Propagated authoritative template_code values through public templates,
  cloned player generals, starter choices, draw results, and public pool data.

2. Display modes

- Added the strict image_display_mode enum:
  - image: WebP-first picture output with PNG and per-item Emoji fallback;
  - emoji_fallback: Emoji-only output with no formal image requests.
- New installations default to image mode; existing installations receive an
  idempotent SQL upgrade.
- Added the global admin selector and preview, with CSRF protection.

3. Runtime integration

- Added a confined manifest resolver and renderer for server-rendered pages.
- Added allowlisted client configuration for dynamic city and map rendering.
- Integrated the resource system into general/recruitment views, city,
  internal affairs, map, profile, research, and shared gameplay resource bars.

4. Build and validation

- assets/images/manifest.json exposes exactly 64 semantic assets.
- The reproducible builder and read-only pixel validator live under tools/.
- All 13 PHP test scripts pass: 689 assertions.
- Repository-wide PHP lint, JavaScript checks, Python compile checks, image
  validation, and git diff --check all pass.

5. Art note

The hierarchy and presentation adapt the bright crystal-city and ornate
Japanese browser-strategy card language visible in the user-provided Megami
